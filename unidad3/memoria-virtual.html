Memoria Virtual ​

Con memoria virtual, cada proceso tiene su propio espacio de direcciones dividido en páginas. Solo algunas páginas necesitan estar en memoria física; el resto puede estar en disco.

Ejercicio 5: Direccionamiento Virtual y Paginación ​

Dado un sistema que utiliza paginación para administrar la memoria. El espacio de direccionamiento virtual es de 7 páginas de 4096 words y la memoria física está dividida en 64 bloques.

a) ¿Cuantos bits componen una dirección virtual?

Cantidad de bits=Bits para número de página+Bits para desplazamientoBits para número de página=⌈log2⁡(Número de páginas)⌉=⌈log2⁡7⌉=3 bitsBits para desplazamiento=log2⁡(Tamaño de página)=log2⁡(4096)=12 bitsTotal bits dirección virtual=Bits para número de página+Bits para desplazamiento=3+12=15 bits

b) ¿Cuántos bits componen una dirección física?

  • La memoria física tiene 64 bloques.
  • Cada bloque tiene el mismo tamaño que una página (4096 words).
  • Entonces, el número total de direcciones físicas es:
Número de direcciones físicas=Número de bloques×Tamaño de bloque=64×4096=262144 wordsBits dirección física=log2⁡(Número de direcciones físicas)=log2⁡(262144)=18 bits

Ejercicio 6: Paginación y Tablas de Páginas ​

Dados los siguientes procesos:

ProcesoTamañoNro. de páginas que ocupa
112288
224576
34096
48192
516384
  • La memoria virtual está dividida en 16 páginas.
  • La tabla de páginas más grande puede ocupar 128 bytes.

El enunciado no da el tamaño de página, pero se puede deducir: los procesos suman 12288 + 24576 + 4096 + 8192 + 16384 = 65536 bytes. Si ocupan justo las 16 páginas de la memoria virtual (como plantea el punto c), cada página es de 65536 / 16 = 4096 bytes (4 KB).

a) Cuantas páginas ocupa cada proceso:

ProcesoTamaño (bytes)Nro. de páginas que ocupa
1122883 (12288 / 4096 = 3)
2245766 (24576 / 4096 = 6)
340961 (4096 / 4096 = 1)
481922 (8192 / 4096 = 2)
5163844 (16384 / 4096 = 4)

Total: 3 + 6 + 1 + 2 + 4 = 16 páginas, justo el tamaño de la memoria virtual.

b) ¿Cuántos bits se utilizan para almacenar la información de cada página?

  • La información de cada página se guarda en una entrada de la tabla de páginas.
  • La tabla más grande es la que mapea toda la memoria virtual: 16 entradas, y puede ocupar 128 bytes. Entonces:
Tamaño de cada entrada=128 bytes16 entradas=8 bytes=64 bits

c) ¿Si los procesos ocuparían el total de la memoria virtual, de cuantos bits sería el sistema de direccionamiento?

  • Si los procesos ocuparan el total de la memoria virtual (16 páginas de 4096 bytes cada una):
Tamaño total de memoria virtual=16×4096=65536 bytesBits para direccionamiento=log2⁡(65536)=16 bits

Ejercicio 7: Paginación y Gestión de Memoria ​

En un sistema con gestión de memoria por demanda de página, con direcciones virtuales de 36 bits, de los cuales los 13 menos significativos son utilizados para indicar el desplazamiento dentro de la página y los restantes el número de página.

a) ¿Cuál es el tamaño de la página?

  • El tamaño de la página se determina por los bits de desplazamiento.
  • Dado que los 13 bits menos significativos se utilizan para el desplazamiento:
Tamaño de la página=2Bits de desplazamiento=213=23×210=8 KB

b) ¿Cuántas páginas diferentes puede haber?

  • El número de páginas se determina por los bits restantes en la dirección virtual.
  • Dado que la dirección virtual tiene 36 bits y 13 se utilizan para el desplazamiento, los bits restantes son:
Bits para número de página=36−13=23 bitsNúmero de páginas=2Bits para número de página=223=23×220=8 M páginas

c) Si se tienen 512Mb de memoria física ¿Cuántos marcos de página puede haber?

  • La memoria física es de 512 MB.
  • El tamaño de cada marco de página es igual al tamaño de la página (8 KB).
  • Entonces, el número de marcos de página es:
Número de marcos de página=Memoria físicaTamaño de página=512×220 bytes8×210 bytes=229−13=216=26×210=64 K marcos

d) ¿Cuál será el tamaño de la tabla de páginas que requiera traducir toda la memoria virtual si las entradas de la tabla de página son de 64 bits?

  • El número total de páginas es 2^23.
  • Cada entrada de la tabla de páginas es de 64 bits (8 bytes).
  • Entonces, el tamaño total de la tabla de páginas es:
Tamaño de la tabla de páginas=Número de páginas×Tamaño de cada entrada=223×8 bytes=223×23 bytes=226 bytes=26×220 bytes=64 MB
