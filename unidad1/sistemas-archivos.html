Sistemas de Archivos ​

Directorio Raíz ​

El directorio raíz es el directorio principal del sistema de archivos, que contiene todos los archivos y directorios del sistema.

En Linux ​

  • Representado por /
  • Jerarquía única
  • Distinción entre mayúsculas y minúsculas
  • Todos los dispositivos se montan en esta jerarquía

En Windows ​

  • Representado por C:\ (y otras letras para diferentes unidades)
  • Jerarquía múltiple
  • No distingue entre mayúsculas y minúsculas
  • Cada unidad tiene su propia jerarquía

Jerarquía de archivos en Linux ​

  • (a) Antes de montarse, los archivos del CD-ROM no están disponibles
  • (b) Después de montarse, los archivos del CD-ROM están disponibles en /mnt/cdrom

Tipos de Archivos ​

Archivos de Bloques ​

  • Almacenan datos en bloques de tamaño fijo
  • Se accede a los bloques de forma aleatoria
  • Ejemplo: disco duro
  • Ejemplo en Linux: /dev/sda

Archivos de Caracteres ​

  • Almacenan datos en secuencia
  • Se accede a los datos de forma secuencial
  • Ejemplo: impresora
  • Ejemplo en Linux: /dev/tty0

Sistema de Archivos ​

Un sistema de archivos es una estructura de datos que:

  • Almacena archivos y directorios
  • Permite acceder a los archivos y directorios
  • Gestiona el espacio en disco
  • Proporciona mecanismos de seguridad y control de acceso

Componentes de un Sistema de Archivos ​

  1. Bootblock: Contiene el código para arrancar el sistema operativo
  2. Superblock: Contiene información sobre el sistema de archivos (tamaño, estado, etc.)
  3. Inodos: Contienen metadatos de los archivos (permisos, propietario, ubicación de los datos, etc.)
  4. Bloques de datos: Almacenan el contenido de los archivos

Operaciones comunes en Sistemas de Archivos ​

  • Crear un archivo
  • Eliminar un archivo
  • Abrir un archivo
  • Cerrar un archivo
  • Leer de un archivo
  • Escribir en un archivo
  • Cambiar atributos de un archivo
  • Crear un directorio
  • Eliminar un directorio
  • Listar el contenido de un directorio
