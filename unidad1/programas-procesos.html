Programas y Procesos ​

Diferencias entre Programa y Proceso ​

Programa ​

Un programa es una entidad estática que existe en el almacenamiento secundario:

  • Archivo ejecutable (código binario)
  • No tiene identificador, estado, recursos ni padre
  • Es una secuencia de instrucciones
  • Permanece inactivo hasta que se ejecuta

Proceso ​

Un proceso es una entidad dinámica que representa la ejecución de un programa:

  • Programa en ejecución (cargado en memoria)
  • Tiene identificador, estado, recursos y padre
  • Tiene un contador de programa que indica la siguiente instrucción a ejecutar
  • Tiene un espacio de direcciones en memoria
  • Tiene una pila para almacenar variables locales y direcciones de retorno
  • Tiene un conjunto de registros del procesador

Un programa es un archivo ejecutable guardado en disco: una secuencia de instrucciones. Es estático: no tiene PID, estado ni recursos.

Características de los Threads ​

  • Comparten el mismo espacio de direcciones del proceso
  • Tienen su propio contador de programa
  • Tienen su propia pila
  • Comparten recursos del proceso (archivos abiertos, variables globales, etc.)
  • Son más eficientes para la creación y cambio de contexto que los procesos

Estados de un Proceso ​

Un proceso puede encontrarse en diferentes estados durante su ciclo de vida:

  1. Nuevo: el proceso fue creado, pero el SO todavía no lo admitió
  2. Listo: puede ejecutarse, pero espera que el planificador lo elija
  3. En ejecución: está usando la CPU en ese instante
  4. Bloqueado: espera un evento externo (E/S, señal, etc.)
  5. Terminado: el proceso finalizó su ejecución

Estados de un proceso

Tocá una transición habilitada para mover el proceso.

Creación de Procesos ​

En sistemas tipo UNIX, los procesos se crean mediante la llamada al sistema fork():

  1. El proceso padre llama a fork()
  2. El sistema operativo crea una copia del proceso padre
  3. El proceso hijo recibe un identificador único (PID)
  4. Ambos procesos continúan ejecutándose desde el punto donde se llamó a fork()

Para ejecutar un programa diferente, el proceso hijo puede llamar a exec().
