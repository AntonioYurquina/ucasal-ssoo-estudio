Fecha y Hora en Sistemas Operativos ​

Consultar fecha y hora en Linux/Windows ​

Linux ​

bash
# Fecha
$ date

# Hora
$ date +%T

Windows ​

bash
# Fecha
$ date

# Hora
$ time

Pasos para obtener la fecha y hora ​

Dentro del SO ​

  • El SO lee la hora del RTC al iniciar
  • Mantiene un temporizador interno, a través de interrupciones/pulsos periódicos (1ms por ej.)
  • El SO calcula la fecha y hora actual a partir de la fecha y hora inicial y el tiempo transcurrido desde que se inició
  • Eventualmente, podría sincronizarse vía Internet utilizando el protocolo NTP (Network Time Protocol).

Fuera del SO ​

  • El hardware tiene un RTC (Real Time Clock) que funciona con una batería/pila
  • El RTC mantiene la hora actual
