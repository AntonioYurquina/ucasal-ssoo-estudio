Dispositivos de E/S e Interrupciones ​

Iniciar un dispositivo de E/S y obtener una interrupción ​

El proceso para iniciar un dispositivo de entrada/salida y manejar las interrupciones que genera sigue estos pasos:

  1. El driver le indica al controlador lo que debe hacer
  2. El controlador le indica al dispositivo lo que debe hacer
  3. Si el controlador de interrupciones está preparado, el dispositivo le indica al CPU que terminó
  4. El controlador de interrupciones indica el número de Bus

Animación: iniciar una E/S y obtener una interrupción

Un proceso pide leer del disco. La CPU ejecuta el driver.

DMA (Direct Memory Access) ​

El DMA (Acceso Directo a Memoria) es una técnica que permite a los dispositivos de E/S transferir datos directamente a la memoria principal sin intervención de la CPU.

Animación: transferencia con DMA

Un proceso pide leer 4 bytes del disco a la memoria (desde 1000).

Funcionamiento del DMA ​

  1. La CPU le indica al controlador de DMA lo que debe hacer
  2. El controlador de DMA gestiona la transferencia de datos entre el dispositivo y la memoria
  3. Cuando el DMA termina, genera una interrupción para notificar a la CPU

Ventajas del DMA ​

  • Reduce la carga de trabajo de la CPU
  • Aumenta el rendimiento del sistema
  • Permite transferencias de datos a alta velocidad
  • Libera a la CPU para realizar otras tareas mientras se transfieren los datos

Tipos de Transferencia de E/S ​

E/S Programada ​

  • La CPU ejecuta instrucciones que controlan directamente el dispositivo de E/S
  • La CPU verifica constantemente el estado del dispositivo (polling)
  • Ineficiente para dispositivos lentos

E/S por Interrupciones ​

  • La CPU inicia la operación de E/S y continúa con otras tareas
  • Cuando el dispositivo termina, genera una interrupción
  • La CPU atiende la interrupción y procesa los datos
  • Más eficiente que la E/S programada

E/S por DMA ​

  • La CPU configura el controlador de DMA
  • El DMA gestiona la transferencia de datos
  • La CPU recibe una interrupción cuando la transferencia termina
  • Muy eficiente para transferencias de grandes cantidades de datos
