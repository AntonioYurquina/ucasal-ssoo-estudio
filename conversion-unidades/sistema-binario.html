Sistema binario ​

Unidades de memoria con prefijos binarios: cada unidad es 2¹⁰ = 1.024 veces la anterior. Para los prefijos de potencias de 10, ver el sistema decimal.

Coma para decimales. 1 KB = 210 B = 1.024 B.
