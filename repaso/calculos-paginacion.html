Cálculos de Paginación ​

Ejemplo: sistema de 42 bits, páginas de 8 KB, memoria física de 8 GB

En un sistema de 42 bits, con páginas de memoria de 8 KB y memoria física de 8 GB.

a. ¿Cuántos bits se utilizan para el acceso interno de la página?

b. ¿Cuántos bits se utilizan para el acceso a la tabla de paginación?

c. ¿En cuántas páginas se divide el espacio de direccionamiento virtual?

d. ¿Cuántos marcos de página posee la memoria?

e. ¿Cuánta memoria se puede direccionar?

Datos en potencias de 2:

  • Dirección virtual: 42 bits
  • Página: 8 KB = 23×210=213 bytes
  • Memoria física: 8 GB = 23×230=233 bytes

a. ¿Cuántos bits se utilizan para el acceso interno de la página?

Son los bits del desplazamiento: 8 KB=213⇒13 bits

b. ¿Cuántos bits se utilizan para el acceso a la tabla de paginación?

Son los bits del número de página: 42−13=29 bits

c. ¿En cuántas páginas se divide el espacio de direccionamiento virtual?

229=29×220=512 M páginas

d. ¿Cuántos marcos de página posee la memoria?

233213=220=1 M marcos

e. ¿Cuánta memoria se puede direccionar?

242 bytes=22×240 bytes=4 TB
Ejemplo: 2 niveles de 8 bits cada uno, páginas de 2 KB, memoria física de 1 MB

En un sistema con paginación de 2 niveles de 8 bits cada uno, con páginas de 2 KB y memoria física de 1 MB.

a. ¿Cuántos bits se utilizan para el acceso interno de la página?

b. ¿Cuántos bits se utilizan para el acceso a la tabla de paginación?

c. ¿En cuántas páginas se divide el espacio de direccionamiento virtual?

d. ¿Cuántos marcos de página posee la memoria?

e. ¿Cuánta memoria se puede direccionar?

f. ¿Se puede utilizar toda la memoria física?

Datos en potencias de 2:

  • Dirección virtual: 2 niveles de 8 bits = 8+8=16 bits
  • Página: 2 KB = 21×210=211 bytes
  • Memoria física: 1 MB = 220 bytes

Dirección virtual de 16 bits: número de página (5) │ desplazamiento (11)

a. ¿Cuántos bits se utilizan para el acceso interno de la página?

Son los bits del desplazamiento: 2 KB=211⇒11 bits

b. ¿Cuántos bits se utilizan para el acceso a la tabla de paginación?

Son los bits del número de página: lo que queda de la dirección después del desplazamiento.

16−11=5 bits

c. ¿En cuántas páginas se divide el espacio de direccionamiento virtual?

25=32 páginas

d. ¿Cuántos marcos de página posee la memoria?

220211=29=512 marcos

e. ¿Cuánta memoria se puede direccionar?

216 bytes=26×210 bytes=64 KB

f. ¿Se puede utilizar toda la memoria física?

No: un proceso solo puede direccionar 64 KB (32 páginas), pero la memoria física es de 1 MB (512 marcos). Un solo proceso nunca puede usar más de 32 de los 512 marcos (entre varios procesos sí se puede ocupar toda la memoria).

Ejemplo: sistema de 64 bits, páginas de 8 KB, 32 GB de RAM

En un sistema de 64 bits, con páginas de memoria de 8Kb y memoria física de 32Gb.

a. ¿Qué tipo de tabla utilizaría en este caso?

b. ¿Cuántos bits se utilizan para el acceso a la tabla de paginación?

c. ¿Cuántos bits se utilizan para el acceso interno de la página?

d. ¿En cuántas páginas se divide el espacio de direccionamiento virtual?

e. ¿Cuántos marcos de página posee la memoria?

f. ¿Cuánta memoria se puede direccionar?

Datos en potencias de 2:

  • Página: 8 KB = 23×210=213 bytes
  • Memoria física: 32 GB = 25×230=235 bytes
  • Dirección virtual: 64 bits

a. ¿Qué tipo de tabla utilizaría en este caso?

Una tabla de páginas invertida, normalmente con tabla hash. Una tabla convencional necesitaría 251 entradas, lo cual es inviable. La invertida tiene una entrada por marco físico: solo 222 entradas (ver punto e). Otra opción válida es una tabla multinivel.

b. ¿Cuántos bits se utilizan para el acceso a la tabla de paginación?

Son los bits del número de página:

64−13=51 bits

c. ¿Cuántos bits se utilizan para el acceso interno de la página?

Son los bits del desplazamiento (offset):

8 KB=213⇒13 bits

d. ¿En cuántas páginas se divide el espacio de direccionamiento virtual?

251=21×250=2 P páginas=2.251.799.813.685.248 páginas

e. ¿Cuántos marcos de página posee la memoria?

235213=222=22×220=4 M marcos=4.194.304 marcos

f. ¿Cuánta memoria se puede direccionar?

264 bytes=24×260 bytes=16 EB (exabytes)

Ese es el espacio virtual. La memoria física realmente disponible es de 32 GB.
