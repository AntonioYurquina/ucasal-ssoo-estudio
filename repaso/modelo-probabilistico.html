Modelo Probabilístico de Multiprogramación ​

Con n procesos en memoria que esperan E/S una fracción p del tiempo:

CPU ociosa=pnUso de CPU=1−pnCPU por proceso=1−pnn
Ejemplo: 3 procesos con 50% de tiempo de E/S

Datos: n=3, p=0.5

  1. CPU ociosa = 0.53=0.125=12.5%
  2. Uso de CPU = 1−0.125=0.875=87.5%
  3. CPU por proceso = 0.8753≈0.29=29%
Ejemplo: 2 procesos con 50% y 90% de tiempo de E/S

Si cada proceso tiene su propia probabilidad, la CPU queda ociosa cuando todos esperan a la vez:

CPU ociosa=p1×p2×…×pnUso de CPU=1−(p1×p2×…×pn)

Datos: p1=0.5, p2=0.9

  1. CPU ociosa = 0.5×0.9=0.45=45%
  2. Uso de CPU = 1−0.45=0.55=55%
  3. Si se reparte en partes iguales: 0.552=0.275≈27.5% por proceso. (En realidad el proceso que espera menos E/S usa más CPU.)
